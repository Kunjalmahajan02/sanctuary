# Kunjal Mahajan — A Botanical Sanctuary

A living portfolio: a painted sky of floating islands, animated in WebGL, with
four places to step inside.

| Island | Place | Content |
| --- | --- | --- |
| Front glasshouse | The Glasshouse | Projects |
| Telescope observatory | The Observatory | Research |
| Upper pavilion | The Pavilion | Creative |
| Gazebo with the postbox | The Post Garden | Contact, résumé, GitHub, LinkedIn |

Live at https://kunjalmahajan02.github.io/sanctuary/

All wording lives in `js/content.js`. The Pavilion images and the résumé are
served from the main site, kunjalmahajan02.github.io.

Run locally with `python -m http.server 5173` and open http://localhost:5173.
